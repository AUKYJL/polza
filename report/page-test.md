# Как проверял

Проверил загрузку /companies, поиск по названию, фильтр по городу и их совместную работу. Также проверил сохранение фильтров после перезагрузки, сброс, пустую выдачу, пагинацию и отображение на узком экране. Дополнительно проверил SQL-подобную строку в поиске — она обрабатывается как обычный текст без ошибки.
